Как это настроить (5 минут)

  1. 1. Создайте таблицу. В Google Sheets сделайте два листа с ровно такими названиями и шапкой в первой строке:
    лист players лист nick_history
    game_idgame_id
    current_nicknick
    levelsource
    noteseen_at
    sourceremoved
    created_atremoved_at
    updated_at
    deleted
    Кнопка «Создать листы с шапкой» ниже сделает это сама через API (если сервис разрешает запись).
  2. 2. Подключите таблицу в сервисе. SheetDB: New API → Google Sheets → вставьте ссылку на таблицу → скопируйте API ID. Sheetson: откройте доступ к таблице для google@sheetson.com и возьмите ключ в панели.
  3. 3. Вставьте ключ/ID в поля выше, нажмите «Сохранить настройки» → «Проверить подключение» → «Полная синхронизация».
  4. 4. Повторите шаг 3 на других устройствах — они получат те же данные из таблицы при открытии сайта.
Важно про безопасность: сайт статический, поэтому ключ сервиса хранится в браузере и виден в исходниках страницы. Не публикуйте ссылку на сайт в открытом доступе, если данные приватны, и не используйте здесь личные документы Google. Для полностью закрытой схемы нужен бэкенд (Google Apps Script или OAuth) — скажите, если переключиться на неё.
Лимиты запросов. Бесплатный SheetDB — 500 запросов в месяц, поэтому читаем пачками по 100 строк и отправляем только изменения. При 1000 игроков первая полная загрузка — примерно 10–20 запросов; дальше по 2 запроса на отправку изменений и по несколько на чтение. «Автосинхронизация» по умолчанию — раз в 10 минут и только при открытой странице.

Данные хранятся в этом браузере (localStorage) и синхронизируются с Google Sheets при включённой синхронизации. Перед массовыми изменениями сделайте резервную копию на вкладке «Бэкап».
