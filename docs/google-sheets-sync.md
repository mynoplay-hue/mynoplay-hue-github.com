# Google Sheets — синхронизация справочника ников

Сайт статический (GitHub Pages), серверного бэкенда нет. Поэтому браузер работает
с Google Sheets через **сервис-посредник**, который превращает листы в REST API.

Поддерживаются два провайдера (переключаются в интерфейсе, вкладка «Sheets»):

| Провайдер | Что нужно | Бесплатный тариф | Запись |
|---|---|---|---|
| **SheetDB** (по умолчанию) | API ID из панели | 500 запросов/мес | да, пачками до 100 строк за запрос |
| **Sheetson** | API key + Spreadsheet ID, доступ для `google@sheetson.com` | 1000 строк на лист | по одной строке за запрос |

## 1. Таблица

Создайте Google Sheets с двумя листами и шапкой **в первой строке** (названия листов
и колонок важны, регистр тоже). Кнопка «Создать листы с шапкой» в интерфейсе может
сделать это сама, если листы пустые.

**Лист `players`**

| game_id | current_nick | level | note | source | created_at | updated_at | deleted |
|---|---|---|---|---|---|---|---|

**Лист `nick_history`**

| game_id | nick | source | seen_at | removed | removed_at |
|---|---|---|---|---|---|

Дополнительная колонка `rowIndex` появляется сама — её добавляет сервис, она не мешает.

## 2. Подключение в SheetDB

1. Откройте <https://sheetdb.io>, войдите.
2. **New API** → Google Sheets → вставьте ссылку на свою таблицу.
3. Скопируйте **API ID** из ссылки вида `https://sheetdb.io/api/v1/XXXXXXXX`.
4. В сайте: вкладка **Sheets** → сервис `SheetDB` → вставьте API ID → «Сохранить настройки»
   → «Проверить подключение» → «Полная синхронизация».

## 3. Подключение в Sheetson

1. Откройте доступ к таблице на редактирование для `google@sheetson.com`.
2. В панели Sheetson создайте проект и возьмите **API key** и **Spreadsheet ID**
   (из адреса таблицы: `docs.google.com/spreadsheets/d/**ID**/edit`).
3. В сайте: сервис `Sheetson` → заполните два поля → сохранить → проверить → синхронизировать.

## 4. На втором устройстве

Достаточно один раз вписать тот же API ID/ключ и нажать «Синхронизировать» —
данные приедут из таблицы. Дальше кнопка «Синхронизировать» в шапке делает
полный цикл: сначала забирает изменения из таблицы, потом отправляет локальные.

## Как устроено (важно для понимания расхода запросов)

* Данные всегда лежат локально (`localStorage`), поэтому сайт работает офлайн.
* В таблицу пишутся **только добавления строк** (append-only) — ничего не перезаписывается.
  Состояние сводится по самому свежему `updated_at`; для ников — по `seen_at`/`removed_at`.
* Удаление ника — это строка с `removed = 1`; удаление игрока — строка с `deleted = 1`.
  Так удаления «доезжают» до других устройств и не ломают историю.
* Чтение — страницами по 100 строк (ограничение обоих сервисов).
* Отправка — только изменённое с прошлой отправки, пачками по 100 строк,
  плюс пауза ~0,4 с, чтобы сервис успел сбросить кэш чтения.
* Автосинхронизация — не чаще выбранного интервала и только при открытой странице.

### Примерный расход на 1000 игроков

| Операция | Запросов |
|---|---|
| Первая полная выгрузка (1000 игроков + 1000 ников) | ~20 |
| Обычная синхронизация без изменений | 2–22 (зависит от числа страниц чтения) |
| Синхронизация после правки одного игрока | 1 на запись + чтение |

При бесплатных 500 запросах/мес это ориентировочно 20–50 полных синхронизаций в месяц.
Если нужно чаще — включайте автосинхронизацию раз в 30 минут или переходите на платный тариф.

## Безопасность

Ключ сервиса хранится в `localStorage` браузера и, поскольку сайт статический,
не является секретом от посетителей страницы. Поэтому:

* не используйте личные/приватные документы Google;
* не публикуйте ссылку на сайт в открытом доступе, если данные чувствительны;
* при необходимости закрытой схемы — нужен бэкенд (Google Apps Script Web App или
  OAuth + Sheets API), это отдельная задача.

## Если что-то не работает

| Симптом | Причина / решение |
|---|---|
| «Нет связи с сервисом… CORS» | неверный API ID, таблица не привязана к сервису или сервис недоступен |
| «Сервис вернул ошибку 404» | нет листа с точным названием `players` / `nick_history` |
| Колонки пустые при проверке | нет шапки в первой строке — добавьте вручную или кнопкой «Создать листы с шапкой» |
| Изменения не видны сразу | кэш сервиса: подождите ~15–60 с и нажмите «Загрузить из таблицы» |
| Дубликаты строк в таблице | нормально: журнал append-only; на чтение берётся самая свежая запись |
