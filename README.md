# Справочник ников игроков

Статическое приложение для GitHub Pages: поиск игрока по ID, поиск ID по части ника
(включая старые ники), ручное добавление, импорт списков, история ников,
резервные копии и **синхронизация между устройствами через Google Sheets**.

**Сайт:** <https://mynoplay-hue.github.io/mynoplay-hue-github.com/>

## Возможности

- 🔍 Поиск по ID, по части ника и по нескольким ID сразу
- 📜 История ников игрока: старые ники сохраняются, любой можно сделать текущим
- 📋 Импорт списка в формате `1 "Ник" 7646467 1566560000 9999` с отчётом
  (новые / сменили ник / без изменений / повторы / пропущенные строки)
- ☁️ Синхронизация через Google Sheets (SheetDB или Sheetson) — одна база на всех устройствах
- 💾 Работает без сети: данные локальны, изменения уходят в таблицу при связи
- 📥 Экспорт/импорт JSON, полная очистка

## Настройка синхронизации

Подробная инструкция со схемой листов — [`docs/google-sheets-sync.md`](docs/google-sheets-sync.md).
Коротко: вкладка **Sheets** → выбрать сервис → вставить API ID/ключ → «Проверить подключение» →
«Полная синхронизация». На втором устройстве — те же данные подключения и «Синхронизировать».

## Разработка

Сайт — один файл `index.html`, но собирается из частей, чтобы было удобно править:

```
assets/db.js          хранилище, разбор списков, импорт, поиск (без DOM)
assets/sync.js        синхронизация с Google Sheets (провайдеры, слияние, push/pull)
dev/parts/*.html      разметка страницы
dev/parts/app.js      интерфейс
dev/build.mjs         сборка → index.html
```

```bash
node dev/build.mjs      # пересобрать index.html
python3 -m http.server  # локальный просмотр на http://localhost:8000
```

Правки вносите в `assets/` и `dev/parts/`, затем пересоберите `index.html`
(он коммитится, GitHub Pages отдаёт именно его).

## Структура данных

```jsonc
{
  "version": 2,
  "players": {
    "7646467": {
      "gameId": 7646467,
      "currentNick": "Bazhena",
      "level": 9999,
      "note": null,
      "source": "seed",
      "createdAt": "...", "updatedAt": "...",
      "deleted": false,
      "nicks": [
        { "nick": "Bazhena", "source": "seed", "seenAt": "...", "removed": false, "removedAt": null }
      ]
    }
  },
  "settings": {}
}
```

В Google Sheets те же данные лежат двумя листами (`players`, `nick_history`)
в режиме «только добавление» — подробности в инструкции.
